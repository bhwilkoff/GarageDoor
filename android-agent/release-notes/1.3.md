I was away from home and my garage door stopped answering in Apple Home.
This version fixes why.

- **The hidden screen no longer falls asleep.** Garage Agent runs myQ on
  a screen of its own that you never see. That screen has its own sleep
  timer, and once nothing had tapped on it for a while it went dark. myQ
  drew nothing, so Garage Agent couldn't see the door and Home showed
  "No Response". Garage Agent now checks every few seconds and wakes
  that screen if it has gone dark. Your real screen isn't affected.

**To install:** open this page on your extra Android phone, tap
`garage-agent.apk`, allow the install, and open Garage Agent. Already
have it? Install this right over it. Your Apple Home pairing and settings
stay just as they are.
