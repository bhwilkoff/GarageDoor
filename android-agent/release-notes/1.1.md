Garage Agent should feel less like a settings screen and more like a
note from a friend who set it up for you. So, this version is mostly
about how it talks to you.

- **It tells you when there is an update.** Open Garage Agent and, if a
  newer version is out, a **Download update** button is waiting at the
  top. Updates install right over the old version: your Apple Home
  pairing and settings stay just as they are. You set it up once.
- **A calmer screen.** When everything works, the finished steps stop
  offering buttons you don't need. The technical log is tucked behind
  **Show details**.
- **Plainer words.** "Just now" instead of "0 minutes ago." "Your Home is
  connected." A notification that says what it is doing: watching the
  garage door for Apple Home.
- **A download link that never changes**, plus a QR code on the
  [front page](https://github.com/bhwilkoff/GarageDoor#readme), so you
  can scan it with the Android phone instead of typing a web address.

**To install:** open this page on your extra Android phone, tap
`garage-agent.apk`, allow the install, and open Garage Agent. It walks
you through the rest. Already have 1.0? Install this right over it.
